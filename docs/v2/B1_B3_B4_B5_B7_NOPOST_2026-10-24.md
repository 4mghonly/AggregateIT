## B1 — actual English renderer driven by V2 admitted evidence

`v2_english_application_rehearsal.py` now takes an explicitly synthetic fixture
through the existing B3 evidence graph/journal, B4 native-language editorial
selection, B5 layout contract, B6 telemetry budget and reserved (never sent)
delivery state, **then** renders the actual two-page English Gazette with
`gazette_render.render_p1/render_p2` to memory. It never imports or invokes
the `slide.py` executable path, which otherwise collects, invokes an LLM and
posts to Discord.

The selected synthetic event quotes, dates and source IDs are lifted from the
V2 admission result, **not** a hand-authored fake news feed. Three native
English synthetic event records were admitted (`en-001`, `en-002`, `en-003`),
one Persian-only synthetic event was withheld, and the separate Arabic event
path remained independent. The fixture URLs use `.invalid` and cannot refer
to real publishers. The two English PNGs were rendered at **3840×2160** and
verified by decoding and hashing. Runtime `socket.socket` was blocked.

The adapter sets unknown market, macro, social and claims-count snapshots to
**unavailable**, with `Unrated` event severity and no invented sentiment,
causal analysis, market numbers or publisher independence. The image header
states **SYNTHETIC SAMPLE — NOT LIVE DATA**. Optional CLI output writes to a
caller-chosen existing directory with exclusive-create no-overwrite semantics.

The attached synthetic preview exists only in a disposable local testing
directory; no imagery was posted, committed or transmitted. This is a real
*renderer* integration, **not** actual live source→model→delivery E2E proof.

## B3 — portable external-checkpoint verification contract

`v2_evidence_anchor.py` signs an exact B3 journal receipt using caller-injected
HMAC-SHA256 secret (minimum 32 bytes), names an operator key ID and can link
to the SHA-256 digest of a predecessor anchor. Verification requires the
expected key, canonical UTC issue time, exact journal receipt, authenticated
previous anchor if linked, monotonically nondecreasing sequence and no
different hash at an equal sequence number.

Fault tests cover a valid two-/three-anchor chain, forged MAC, mismatched key,
missing or different predecessor, local **journal+head simultaneous rollback**
compared to a separately retained newer receipt, out-of-order sequence,
same-sequence fork, bad clock and underlength secret. All tests use an openly
synthetic test key and disposable local evidence store.

**Security boundary:** No remote location exists, no remote write occurred,
the signing key is not managed, and authentic publisher provenance is **not**
established. A locally retained anchor can be rolled back with the journal.
Only a genuinely independent, trusted holder of the newer anchor would make
such a rollback detectable after compromise. This is a contract demonstration,
not operational off-host anchoring or production-grade key management.

## B4 — obvious script/label mismatch is now refused

`v2_script_guard.py` checks Unicode **letters** for a majority Latin-script
excerpt under English labels or a majority Arabic-script excerpt under Arabic
labels. `v2_editorial.py` invokes it before native-language excerpt admission.
Contradictory labels are held as `source_script_mismatch`; numeric/no-letter
and severely mixed samples are held instead of silently promoted.

**Critical limitation:** This is a script check, **not** language detection,
publisher identity, linguistic accuracy or translation verification. Persian,
Urdu and Pashto often use the same general Arabic script; a mislabeled Persian
excerpt can pass. Native-Arabic source acceptance and cross-language
translation remain **unverified** without additional evidence. The test suite
explicitly encodes that non-equivalence.

## B5 — direct visual QA found a missing-data semantics defect

Viewing the new actual English page-2 PNG showed empty market charts with
Matplotlib's default numeric **0–1 axes** even though no data existed. The V2
`gazette_render.py` now removes numeric ticks and labels an empty chart
`No verified snapshot` for missing leaders, sector sample, mover scatter,
yield curve and commodities. Verified market zeros still remain `0.00%`.

The initial English page-1 sample showed **0% high/critical** when all three
events were explicitly **Unrated**, which falsely suggested a measured zero.
The renderer now uses `-` until a rated event exists and computes high/critical
share **among rated events only**. Counts and meanings are tested directly.

This fixes two proven misleading missing-data cases, **not** mobile readability
or complete rendered-text clipping. Arabic dense-page legibility and release
font decision remain deferred; no Arabic production renderer was changed.

## B7 — source citation invariant tightened

`v2_shadow_scorecard.validate_run` now rejects reports in which
`items_rendered > items_cited`, even if both counts are at or below selected
event count. Otherwise uncited output could incorrectly appear as a V2
coverage gain. Synthetic scorecard tests cover the refusal.
