## How to review without touching production
Run on the development branch:

```bash
python -m pip install -r requirements.txt pillow beautifulsoup4
python -m unittest -v test_newsletter_themes
python -m unittest -v test_gazette_layout arabic_newsletter.test_arabic.RenderTests
python render_theme_samples.py --out reports/theme-preview
```

For a *real archived Arabic* briefing with validated `briefing.json`:

```bash
python render_theme_samples.py --arabic-json /path/to/briefing.json --out reports/replay-preview
```

For real English data use `--english-json` with a JSON object holding the existing `data` and `analysis` payloads. A PNG-only English workflow artifact does **not** supply these payloads.

## Production safety and rollout gate
1. **No secrets, webhooks, scheduled workflows or database changes** are needed to generate offline samples.
2. Existing production templates remain the default even after this branch is merged; opting in requires explicit environment variables.
3. Do not modify production env vars, dispatch the production workflows with this branch, or merge into `main` before approval.
4. Confirm visual review at native Discord display size: Arabic RTL, long headlines, text truncation, source attribution, missing-data labels, differing headline volumes, page counts, image bytes and all 17 monitored regions.
5. Ensure reference links are in the existing `sources-ar.txt` companion, generated by the current references function. Slide 2 features up to six active regions, and lists any other active regions in its footer instead of treating them as inactive.
6. Roll back by unsetting `GAZETTE_THEME` and `ARABIC_NEWSLETTER_THEME` (or selecting `classic`), after release approval.

## Editorial constraints
- Preserve the validated data and source chain. Rendering performs no inference.
- Missing evidence and missing market quotes are stated as unavailable, not zero or a prediction.
- Arabic stays geopolitical/security focused (no financial section).
- Option-chain data are not fabricated; the English theme omits an options board until sourced structured rows are available.
- Sample fixtures are synthetic; do not represent them as live news.
